# プール・オブ・レイディアンス 日本語化プロジェクト

プール・オブ・レイディアンス（Pool of Radiance）を日本語で遊べるようにする、非公式のファンメイド日本語化プロジェクトです。
Steam で販売されている版を対象にしています。
開発元・販売元とは関係ありません。

- サイト（作品の紹介・入れ方）: https://higesho.github.io/por-ja/
- ダウンロード: [リリース](https://github.com/higesho/por-ja/releases)
- ウルティマ シリーズの日本語化: https://higesho.github.io/ultima-ja/
- マイト・アンド・マジック シリーズの日本語化: https://higesho.github.io/mm-ja/
