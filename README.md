# D&D シリーズ 日本語化プロジェクト

ダンジョンズ＆ドラゴンズ（Dungeons & Dragons）のルールで遊ぶコンピューター RPG を、日本語で遊べるようにする、非公式のファンメイド日本語化プロジェクトです。
GOG.com や Steam で販売されている版を対象にしています。
開発元・販売元とは関係ありません。

- サイト（作品の紹介・入れ方）: https://higesho.github.io/dnd-ja/
- ウルティマ シリーズの日本語化: https://higesho.github.io/ultima-ja/
- マイト・アンド・マジック シリーズの日本語化: https://higesho.github.io/mm-ja/
