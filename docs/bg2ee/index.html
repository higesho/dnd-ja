日本語化プロジェクト

Baldur's Gate II: Enhanced Edition

バルダーズ・ゲートII エンハンスド・エディション 日本語化パッチ

「Baldur's Gate II: Enhanced Edition」の現行版（v2.7）を日本語で遊べるようにする、非公式のファンメイドパッチです。 有志の方による日本語化パッチ（v2.3 対応版）をもとに現行版で動くように作り直し、英語のまま残っていた約5,800件の文章をすべて翻訳しました。 本編シャドウ・オブ・アムン、拡張スロウン・オブ・バールに加えて、追加シナリオ「ブラック・ピットII」や EE で追加された仲間たちの会話まで日本語で遊べます。 ゲームのフォルダにファイルを置き、オプションで言語を日本語にするだけで使えます。

ダウンロード（GitHub）

どんなゲーム？

バルダーズ・ゲートIIは、2000年に BioWare が開発した、D&D 第2版ルールのコンピューター RPG です。エンハンスド・エディションは Beamdog による 2013年のリメイク版で、拡張「スロウン・オブ・バール」と、新しい仲間（ラサード、ドルン、ヘクサート、ニーラ）、闘技場が舞台の追加シナリオ「ブラック・ピットII ～グラディエーターズ・オブ・サーイ～」を収めています。

殺戮の神バールの血を引く主人公は、謎の魔術師イレニカスに囚われたところから物語を始めます。アムンの都アスカトラを拠点に、仲間たちと各地を巡り、やがて自らの出生をめぐる戦いに挑みます。リアルタイムで一時停止できる戦闘で、最大6人のパーティを率いて遊びます。

入れ方

  1. ダウンロードした BaldursGate2EE_JP.zip を展開します。
  2. 中の lang フォルダと override フォルダを、フォルダごとゲームのフォルダ（Baldur.exe があるフォルダ）にコピーします（上書きしてかまいません）。
    Steam のライブラリで「Baldur's Gate II: Enhanced Edition」を右クリックし、「管理」→「ローカルファイルを閲覧」で開けます。
  3. ゲームを起動し、「オプション」→「言語」で日本語（Japanese）を選んで、ゲームを起動し直します。

外し方

  • ゲームのフォルダの lang\ja_JP フォルダと、override フォルダの L_ja_JP.LUA・MEIRYO.ttf を消し、オプションで言語を English などに戻します。セーブデータはそのまま使えます。

元のパッチからの変更点

  • 英語のまま残っていた約5,800件を翻訳しました。ブラック・ピットIIの会話・日誌・闘技場の実況・アイテム・呪文、EE で追加された仲間の会話の残り、v2.3 以降に追加された文章（新しいボイスセットなど）が中心です。
  • 主人公の選択肢は、元のパッチと同じく男性の主人公用と女性の主人公用で口調を分けています。
  • 人名などの固有名詞は、元のパッチの訳に合わせています（デナトン、ヴォグヒルン、”ベイロスの天罰” など）。
  • 台詞の中の <CHARNAME> などが主人公の名前に置き換わらず、そのまま表示されていた箇所を直しました。
  • 画面の項目名（オプションなど）を現行版に合わせて作り直しました。元のパッチの BGEE.LUA と UI.MENU は v2.3 用のため入れていません（現行版のゲームは日本語の言語設定を最初から持っています）。

遊ぶときの注意

  • Steam 版の v2.7.3.0 で確かめています。GOG 版などほかの版の v2.6 以降でも同じ入れ方で使えるはずですが、確かめていません。
  • 本編（シャドウ・オブ・アムン、スロウン・オブ・バール）の大部分は、元のパッチの訳（セガ版の訳がもと）のままです。
  • 声（音声）、ムービー、スタッフクレジットの人名などは英語のままです。
