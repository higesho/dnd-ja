Icewind Dale II + Icewind Dale 2: Enhanced Edition

アイスウィンド・デイル II（IWD2EE）日本語化パッチ

GOG.com 版の「Icewind Dale II」に、ファン製の拡張 MOD「Icewind Dale 2: Enhanced Edition（IWD2EE）」を入れた状態を、日本語で遊べるようにする非公式のファンメイドパッチです。 会話、日誌、品物・呪文・特技・クラス・種族の説明、怪物や人物の名前、画面の文言、用意済みのパーティーとキャラクターの説明まで、ゲームの中の文章を日本語にしています。 IWD2EE が足した仲間の会話や、新しい品物・呪文の説明も日本語になります。 ゲームのフォルダで一度実行するだけで日本語になり、元に戻すこともできます。

ダウンロード（GitHub）

どんなゲーム？

アイスウィンド・デイル II は、2002年に Black Isle Studios が発表した RPG です。舞台はフォーゴトン・レルムの北の果て、アイスウィンド・デイル。 前作から三十年ほどのち、テン・タウンズの港町タルゴスにゴブリンの大群が押し寄せ、傭兵として集まった冒険者たちの戦いが始まります。 やがて一行は、北方を覆う「キマイラ軍団」の陰謀へと踏み込んでいきます。

D&D 第3版のルールを使い、最大 6 人の仲間を一から作って冒険する、戦闘中心のパーティー RPG です。 IWD2EE は、クラス・呪文・品物・怪物の調整、新しい特技や呪文、仲間になる人物、遠回りの少ない道筋などを足す、総合的な改良 MOD です。

必要なもの

  • GOG.com 版 Icewind Dale II（ストアでの名前は「Icewind Dale 2 Complete」）
  • IWD2EE v3.4.2（英語で入れます）
  • 日本語の Windows（表示に Windows の「MS ゴシック」を使います）

入れ方

  1. IWD2EE をいつもどおり入れます。IWD2EE の zip をゲームのフォルダに展開して Setup-iwd2ee.exe を実行し、言語は English を選んで、好きな部品を入れてください。
  2. ダウンロードした IcewindDale2EE_JP.zip を展開し、中のファイル（IWD2JP.exe・IWD2JP.dat・IWD2JP.lua）をゲームのフォルダ（IWD2.exe があるフォルダ）にコピーします。
  3. ゲームのフォルダで IWD2JP.exe をダブルクリックして実行します。結果が表示されたら Enter キーで閉じます。「管理者として実行」はしないでください（ゲームと同じ権限で実行する必要があります）。
  4. IWD2EE.exe からゲームを起動します。

GOG Galaxy で入れた場合、ゲームのフォルダはふつう C:\Program Files (x86)\GOG Galaxy\Games\Icewind Dale 2 です。 IWD2EE の部品を入れ直したときは、そのあとでもう一度 IWD2JP.exe を実行してください。何度実行しても問題ありません。

外し方

  • コマンドプロンプトでゲームのフォルダに移り、IWD2JP.exe /restore と実行すると、最初に控えた英語のファイルに戻ります（控えは IWD2JP_backup フォルダにあります）。セーブデータはそのまま使えます。

遊ぶときの注意

  • v1.0 を「管理者として実行」で入れて、ゲームの文字が消えてしまった場合は、v1.1 の IWD2JP.exe と IWD2JP.dat をゲームのフォルダに上書きコピーし、ふつうに（ダブルクリックで）実行し直してください。
  • 声、動画、絵として描かれた文字は英語のままです。
  • 起動時に出る IWD2EE の解像度選択の窓は英語のままです。
  • キャラクターやセーブデータの名前は英字で入力してください。
  • IWD2EE を入れずに原作だけで使うこともできます。文章は日本語になりますが、行頭・行末の禁則（「。」や「ー」が行の頭に来ないようにする処理）は効きません。
