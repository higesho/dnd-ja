Baldur's Gate: Enhanced Edition / Siege of Dragonspear / Baldur's Gate II: Enhanced Edition

WeiDU の使い方とバルダーズ・ゲート日本語統合環境の作り方

バルダーズ・ゲート EE シリーズの MOD は、ほとんどが「WeiDU（ウェイドゥー）」というインストーラーで入れる形になっています。このページでは WeiDU の使い方と、BG1・Siege of Dragonspear・BG2 を一本のゲームとして続けて遊べる「EET」を、日本語で組み立てる手順を説明します。

BGEE 日本語化修正パッチBGEE差し替え版／WeiDU 版

BGEE だけ、BGEE＋SoD だけで遊ぶなら、各ページの「差し替え版」「かんたんインストール」で足ります。EET や追加 MOD を使うときに WeiDU の手順が必要になります。

WeiDU とは

WeiDU は Infinity Engine（バルダーズ・ゲート、アイスウィンド・デイルなど）用の MOD インストーラーです。MOD には setup-（MOD名）.exe という実行ファイル（中身は WeiDU）と、MOD のフォルダが入っています。実行すると、MOD のフォルダにある手順書を読んで、ゲームのファイルに必要な変更だけを書き込みます。

  • 入れた MOD は、ゲームのフォルダの WeiDU.log に順番どおり記録されます。
  • 元のファイルは自動でバックアップされるので、あとから個別に外せます。
  • 複数の MOD が同じファイルを書き換えても、後から入れたものが前のものの上に変更を重ねるので、共存できます。

WeiDU の基本の使い方

  1. ゲームのフォルダを開く：Baldur.exe と chitin.key があるフォルダです。Steam ならライブラリでゲームを右クリック →「管理」→「ローカルファイルを閲覧」。
  2. MOD を置く：zip の中身（setup-○○.exe と MOD のフォルダ）をそのままゲームのフォルダにコピーします。フォルダの中にさらにフォルダができないように注意してください。
  3. setup-○○.exe をダブルクリック：黒い画面（コマンドプロンプト）が開きます。
  4. 言語を選ぶ：最初に MOD の言語を聞かれます。Japanese の番号を入力して Enter。初めて WeiDU を使うゲームでは、ゲームの言語（ja_JP など）を聞かれることもあります。そのときも日本語を選びます。
  5. 入れる部品を選ぶ：MOD の部品（コンポーネント）ごとに次のように聞かれるので、キーを押して Enter。
    • [I]nstall（入れる）／[N]ot Install（入れない）／[Q]uit（ここで終える）
    • すでに入っている部品は [R]e-Install（入れ直す）／[N]o Change（そのまま）／[U]ninstall（外す）
  6. 結果を確かめる：最後に部品ごとに SUCCESSFULLY INSTALLED と出ていれば成功です。NOT INSTALLED DUE TO ERRORS と出たら、表示されたエラーの文を控えておいてください。何かキーを押すと画面が閉じます。

外すとき

同じ setup-○○.exe をもう一度実行し、外したい部品で U を選びます。いくつも MOD を入れているときは、入れたのと逆の順番で外すのが安全です。

注意

  • ゲームが C:\Program Files の下にあると、Windows の権限の都合で失敗することがあります。EET を組むときは、ゲームのフォルダを丸ごと別の場所（例：D:\Games\BGEE）にコピーして、そちらで作業するのがおすすめです（Steam 版・GOG 版とも、コピーしたフォルダの Baldur.exe から起動できます）。
  • MOD を入れたあとにゲームのアップデートや「整合性の確認」をすると、MOD の変更が壊れることがあります。統合環境は、更新の入らないコピーで組むと安心です。
  • WeiDU の黒い画面では、日本語の部品名が文字化けすることがあります。インストールの結果には影響しません。

日本語統合環境（EET）の作り方

EET（Enhanced Edition Trilogy）は、BGEE＋SoD の内容を BG2EE に取り込み、BG1 から SoD、BG2、スロウン・オブ・バールまでを、同じ主人公で一本のゲームとして続けて遊べるようにする MOD です。EET は BGEE 側の文章をそのまま取り込むので、先に BGEE を日本語化しておくのが大事です。

用意するもの

  • Baldur's Gate: Enhanced Edition と拡張 Siege of Dragonspear（v2.6 以降。Steam 版 v2.7.3.0 で確かめています）
  • Baldur's Gate II: Enhanced Edition（v2.6 以降）
  • どちらもゲームの「オプション」→「言語」で日本語にして、一度起動しておく
  • このプロジェクトの BGEE 修正パッチ、SoD 日本語化パッチ、BG2EE 日本語化パッチ、EET 日本語版（必要なら DSotSC・NTotSC 日本語版も）

手順

  1. ゲームをコピーする（おすすめ）：BGEE と BG2EE のフォルダを、それぞれ Program Files の外にコピーします。以下はコピー先で作業します。
  2. BGEE を日本語化する：BGEE のフォルダに、SoD 日本語化パッチと BGEE 修正パッチ（WeiDU 版）の中身を置き、かんたんインストール.bat をダブルクリックします。DLC Merger による SoD の統合、BGEE 修正、SoD 日本語化が順に入ります（数分かかります）。
    手で入れる場合は setup-DlcMerger.exe（「Merge "Siege of Dragonspear" DLC」を I）→ setup-bgee_jpfix.exe → setup-sod_ja.exe の順です。
  3. BG2EE を日本語化する：BG2EE のフォルダに BG2EE 日本語化パッチの lang と override を上書きコピーします。
  4. EET を入れる：BG2EE のフォルダに EET 日本語版の中身を置き、setup-EET.exe を実行します。
    • 言語は Japanese を選びます。
    • BGEE のフォルダが見つかると「Detected BG:EE directory as …. Is this correct?」と聞かれるので、手順 2 で日本語化した BGEE なら Y。違う場合は N を押し、BGEE のフォルダの場所（例：D:\Games\BGEE）を入力して Enter。
    • 「EET core (resource importation)」を I で入れます。BGEE の全データを取り込むので、30分〜1時間ほどかかります。
  5. 追加の MOD を入れる（任意）：DSotSC 日本語版 → NTotSC 日本語版の順に、同じく BG2EE のフォルダに置いて実行し、言語は Japanese を選びます。ほかの EET 対応 MOD もこの段階で入れます。
  6. EET_end を入れる：最後に setup-EET_end.exe を実行して入れます（EET の仕上げ。必ず一番最後）。
  7. 遊ぶ：BG2EE のフォルダの Baldur.exe を起動し、キャンペーン選択で「バルダーズ・ゲート」を選ぶと BG1 から始まります。

入れる順番のまとめ

順どこになにを
1BGEEDLC Merger（SoD の統合）
2BGEEBGEE 修正パッチ（bgee_jpfix）
3BGEESoD 日本語化（sod_ja）
4BG2EEBG2EE 日本語化パッチ（ファイルを置く）
5BG2EEEET（日本語版）
6BG2EEDSotSC・NTotSC などの MOD（日本語版）
7BG2EEEET_end

うまくいかないとき

  • 「BGEE_JPFIX BG:EE mod is not recognized by EET」と出て EET が止まる：配布元の EET ではなく、このプロジェクトの EET 日本語版を使ってください（日本語化の MOD を BGEE 側に入れても大丈夫なように設定してあります）。
  • 「Invalid directory, or incorrect BG:EE+SoD installation」：BGEE のフォルダの場所が違うか、SoD が統合されていません。手順 2 からやり直してください。
  • BG1・SoD の部分が英語になる：EET を入れる前に BGEE 側の日本語化（手順 2）が済んでいたか確かめてください。BGEE を日本語化し直したあとは、EET を入れ直す必要があります。
  • 「SUCCESSFULLY INSTALLED」と出ない：エラーの文と、ゲームのフォルダの WeiDU.log、SETUP-○○.DEBUG を添えて GitHub の Issues で知らせてください。
