Northern Tales of the Sword Coast v5.0.0

ノーザン・テイルズ・オブ・ザ・ソードコースト（NTotSC）日本語版

「Northern Tales of the Sword Coast（NTotSC）」は、バルダーズ・ゲート（BG1）の北部に新しいエリアとクエスト、仲間「ウィル・オハラ」を加える MOD です。 この配布物は、NTotSC v5.0.0 本体に日本語の言語ファイルを加えたものです。会話・日誌・アイテムなど、MOD のすべての文章を日本語にしています。EET（BG1 部分）用です。

ダウンロード（GitHub）

どんな MOD？

NTotSC は SirBillyBob が作った MOD を、K4thos と jastey が BGT・BGEE・EET 向けにまとめ直したものです。ソードコースト北部の新しい土地で、いくつものクエストと出会いが待っています。DSotSC と一緒に遊ぶこともできます。

画面

入れ方

  1. EET を入れた BG2EE のフォルダに、NTotSC_v5.0.0_JP_v1.0.zip の中身を置きます（EET 日本語版を先に入れてください。DSotSC も使う場合は DSotSC を先に）。
  2. setup-ntotsc.exe を実行し、言語は Japanese を選びます。部品は必要なものを I で入れます。
  3. 最後に setup-EET_end.exe を実行します。

WeiDU の使い方と、BGEE・SoD・BG2EE・EET をまとめて日本語で遊ぶ手順は WeiDU の使い方とバルダーズ・ゲート日本語統合環境の作り方で詳しく説明しています。

元の MOD から変えたところ

  • ntotsc/language/japanese/ に日本語の言語ファイルを追加し、ntotsc/ntotsc.tp2 の言語の選択肢に Japanese を加えました。それ以外は元の MOD のままです。
  • ウィル・オハラの声は英語です（部品「英語サウンドセット」）。
