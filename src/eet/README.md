# EET（エンハンスド・エディション・トリロジー）日本語版のソース

EET（WeiDU の MOD）の文字列ファイル（`.tra`）に日本語を入れるための Python の道具です。EET 本体は含みません。

## 組み立て
- 必要なもの: Python 3
- `index.py` でゲームのデータから文字列の使われ方の索引を作り、`eetmatch.py` で EET の文字列と BGEE の訳の対応を調べます。
- `eet_tra.py` で、EET の英語の `.tra` の各文字列に既存の訳を当てた対応表（`eet_tra_map.json`）を作ります。
- `fixtra.py`（`textfix.py` を使う）で、日本語の `.tra` の性別の書き分けを展開し、EE のエンジンで文章が欠ける半角空白を直します。
- `tlk.py`・`tra.py`・`alltr.py` は TLK・.tra・訳のデータを読む部品です。

## 含まれないもの（各自用意）
- EET 本体、BGEE・BG2EE のゲームのファイル
- 訳のデータ（`out/`、`batches/` など）
- 道具の中のゲームや作業フォルダの場所は自分の環境に合わせて直してください。
